## Selected Work

### Machine Learning & Pattern Analysis
Built and visualized 2D decision boundaries for the Perceptron Learning Algorithm, using the results to examine its limitations on non-linearly separable data and motivate kernel methods.

### Distributed System Fault Injection Framework
Developed a Python simulation framework to evaluate trust-algorithm reliability in distributed satellite-constellation networks. Implemented Triple Modular Redundancy and software-level redundancy to benchmark resilience under node faults and malicious attacks.

### Real-Time Gesture Recognition System
Created a low-latency computer-vision pipeline with Python, OpenCV, and MediaPipe for hand-landmark tracking and real-time gesture classification. Added adaptive thresholding, noise removal, and a rule-based state machine for control commands.

### Deep Learning Medical Image Analysis
Fine-tuned a ResNet-50 model for pneumonia detection, improving performance through dataset refinement, hyperparameter tuning, and cross-validation.

### IEEE-754 Floating-Point Unit
Designed and verified a 32-bit single-precision floating-point adder in Verilog, with an FSM-based pipeline-control design to improve hardware efficiency.
